Log Monitor

Fetch the latest log entries from files inside var/log without manually opening server log files.

Log Request

Choose a log file, number of entries, and an optional keyword filter.

var/log/

Examples: log1.txt, apache/log3.txt

Leave empty to return the newest entries without filtering.
